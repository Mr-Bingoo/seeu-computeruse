SeeU 浏览器助手 · 隐私说明

一句话:插件不联网,只和你电脑上的 SeeU 说话;只碰你允许过的网站;代码全部公开。

1. 不联网

插件不连接任何服务器,不上传、不收集任何数据。它只通过 Chrome 官方的「本机消息」功能,和你电脑上的 SeeU 程序交换消息, 消息不出你的电脑。别的插件、别的网站都连不上这条通道(只认这个插件的编号)。

2. 明确的边界:只碰你允许的网站

  • 装好后插件什么网站都碰不了。你在某个网页上点插件图标、选「允许这个网站」,它才能操作这个网站。
  • 允许名单随时在插件弹窗里能看、能删。没允许的网站,插件连网址都看不到。
  • 要碰一个网站得两关都过:Chrome 自己的权限系统给了授权(只能你亲手点),而且它在 SeeU 的允许名单里。 名单就存在你电脑上(~/.seeu/seeu_web/allow.json),Safari 那条路也认同一份;在哪边移除,两边都不碰了。

3. 不碰的东西

  • 密码框、新密码框、验证码框、银行卡框:不读、不填。改密码、输验证码这一步请你自己来。
  • 不替你提交表单、不替你下单付款:要提交,必须由调用它的人明确去点那个按钮。
  • Chrome 自己的设置页、应用商店:Chrome 本身就不许任何插件碰。

4. 看得见它在干活

插件每次替 SeeU 做事,浏览器右上角的图标都会出现一个紫点,几秒后消失。

5. 代码公开

插件、本机中转程序、SeeU 的全部代码都在 SeeU 文件夹里(seeu/web/),开源后在 GitHub 上,谁都可以看。 不想用了:在 chrome://extensions 里移除插件,再运行 python3 -m seeu.web.install uninstall 撤销本机登记。
